# 部署说明

本项目是一个标准的 Flask 应用，只有 `Flask` 与 `openpyxl` 两个运行时依赖，数据库使用文件型 SQLite，部署成本很低。

| 方式 | 适用场景 | 访问地址 |
| --- | --- | --- |
| 本地运行 | 开发、演示、录屏 | `http://127.0.0.1:8000` |
| 局域网访问 | 同宿舍/实验室演示 | `http://<内网IP>:8000` |
| 云服务器 + Nginx | 课程作业要求中的「云端部署」 | `http://<公网IP>` 或域名 |
| Docker | 一键部署、环境隔离 | `http://<主机IP>:8000` |

---

## 1. 本地运行

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py --demo             # 首次启动带演示数据
```

- 默认监听 `127.0.0.1:8000`，数据库文件位于 `data/address_book.db`；
- 换端口：`python app.py --port 8123`；
- 自定义数据库：`python app.py --db /var/lib/address-book/data.db` 或设置环境变量 `ADDRESS_BOOK_DB`。

## 2. 局域网访问

```bash
python app.py --host 0.0.0.0 --port 8000
```

在 Windows 防火墙中放行 8000 端口（或首次运行弹窗时选择「允许访问」），同网段设备访问 `http://<本机内网IP>:8000` 即可。

## 3. 云服务器部署（Ubuntu 22.04 / 阿里云、华为云）

以下步骤在全新的 Ubuntu 22.04 云服务器（1 核 2G 即可）上验证。

### 3.1 安装运行环境

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip nginx git
sudo mkdir -p /opt/address-book && sudo chown $USER:$USER /opt/address-book
git clone <你的仓库地址> /opt/address-book
cd /opt/address-book
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt gunicorn
```

### 3.2 用 gunicorn 启动

```bash
gunicorn --workers 2 --bind 127.0.0.1:8000 "app:create_app()"
```

`create_app` 是应用工厂，`"app:create_app()"` 写法可以让 gunicorn 直接加载，无需额外 `wsgi.py`。

### 3.3 配置 systemd 守护进程

创建 `/etc/systemd/system/address-book.service`：

```ini
[Unit]
Description=Address Book (Flask)
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/address-book
Environment="ADDRESS_BOOK_DB=/var/lib/address-book/data.db"
ExecStart=/opt/address-book/.venv/bin/gunicorn --workers 2 --bind 127.0.0.1:8000 "app:create_app()"
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo mkdir -p /var/lib/address-book
sudo chown -R www-data:www-data /var/lib/address-book /opt/address-book
sudo systemctl daemon-reload
sudo systemctl enable --now address-book
sudo systemctl status address-book
```

### 3.4 Nginx 反向代理

创建 `/etc/nginx/sites-available/address-book`：

```nginx
server {
    listen 80;
    server_name _;                       # 有域名时改成你的域名

    client_max_body_size 12m;            # 与导入文件大小限制保持一致

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/address-book /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 3.5 安全组 / 防火墙

在阿里云或华为云控制台的**安全组入方向**放行：

- `22`（SSH，建议限制来源 IP）
- `80`（HTTP）

如果跳过 Nginx 直接用 8000 端口，还需要放行 `8000`。

### 3.6 可选：HTTPS

有域名时可用 certbot 一键签发证书：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

## 4. Docker 部署

```bash
docker build -t address-book .
docker run -d --name address-book -p 8000:8000 \
  -v $(pwd)/data:/data \
  address-book
```

- 镜像内使用 gunicorn（2 个 worker）监听 8000 端口；
- `/data` 为数据库卷，**务必挂载**，否则重建容器会丢失数据；
- 首次部署如需演示数据，可在容器内执行 `python app.py --demo`，或直接通过页面新建联系人。

---

## 5. 生产环境注意事项

1. **数据备份**：SQLite 数据全部在 `ADDRESS_BOOK_DB` 指向的文件中，定期备份该文件即可；WAL 模式下备份前建议执行 `sqlite3 data.db "PRAGMA wal_checkpoint(TRUNCATE);"`。
2. **并发写入**：本项目定位为个人/小团队通讯录，SQLite 足够；若需要多人高并发写入，可将 `backend/db.py` 替换为 PostgreSQL 等数据库。
3. **上传大小**：Flask 侧限制 12MB、业务侧限制 10MB，若通过 Nginx 反向代理，`client_max_body_size` 需要同步调整。
4. **编码**：导出文件包含中文表头与文件名，Nginx / gunicorn 默认 UTF-8 即可正常工作。
5. **不要用 `flask run` 或 `app.run()` 直接暴露公网**，它们只是开发服务器。

## 6. 关于加分项（云端部署）

作业中的「Web 部署（可选，15 分）」要求部署到云服务器（`localhost` 不算）。仓库已经提供：

- 容器化 `Dockerfile`（gunicorn 生产启动命令）；
- 本文档中的 systemd + Nginx 完整配置示例；
- 通过 `ADDRESS_BOOK_DB` 环境变量外置数据库，方便挂载数据卷。

购买云服务器（阿里云/华为云学生机均可）后按第 3 节或第 4 节操作，约 10 分钟即可获得公网访问地址，把地址填入博客的「项目地址」一节即可。
