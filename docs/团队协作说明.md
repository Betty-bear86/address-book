## 二、协作方式（XP 实践）

1. **先定契约再并行**：动手前先约定 API 字段表与 Excel 列格式，前后端按契约各自开发，用固定的 JSON 样例联调，避免"各写各的"。
2. **小步提交**：每个功能点单独提交，提交信息统一 `type(scope): subject`，保证任何一次提交都能说明"改了什么、为什么改"。
3. **分支 + PR**：功能在 `feat/*` 分支开发，合并前互相 review 一次，再通过 Pull Request 合入 `main`。
4. **结对排查**：Excel 导入与星标状态同步这两处问题由两人结对定位，一人读代码一人复现。
5. **每日同步 10 分钟**：对齐当天目标、接口变更与阻塞点，接口一旦变更立刻在群里同步并更新文档。

## 三、接口与数据契约

- 联系人：`id / name / group / company / department / title / note / starred / methods[] / created_at / updated_at`
- 联系方式：`type ∈ {phone,email,wechat,qq,address,other}`、`label`（工作/个人/家庭/学校）、`value`、`primary`（每个联系人唯一）
- Excel：`姓名 | 分组 | 公司 | 部门 | 职位 | 电话1..n | 邮箱1..n | 微信 | QQ | 地址 | 其他 | 备注 | 星标 | 创建时间`
